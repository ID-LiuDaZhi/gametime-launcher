## 已知阻塞

本地新版 EXE 编译通过后，Windows 在部署阶段拒绝文件，报告“文件包含病毒或潜在的垃圾软件”，随后生成文件已不存在。没有据此断定检测为误报，也没有关闭防护或绕过拦截。

当前电脑根目录保留的是原先的 4608 字节启动器；它不包含手机 HTTP 服务。多手机相关最新修改保存在源码中。编译检查成功、模拟页面测试成功和手机实机可用是不同的状态。

仓库公开提供基础启动器 EXE，并通过发布流程生成 `v0.1.0-preview` 游戏大厅便携包。该预览版不启用手机服务或二维码入口，基础启动器对应 `release/Launcher.Baseline.cs`；没有把遭拦截的联网服务启动器作为下载发布。预览版下载不等于实体手柄、手机或实际游戏游玩验收通过。

预览包现已发布至 GitHub Releases：完整 ZIP、基础启动器 EXE、SHA-256 校验文件均已上传。云端构建、游戏扫描、多手机逻辑、模拟页面及便携包文件检查均通过；这次发布没有新增手机或实际游戏游玩的实机验收结论。
